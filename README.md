# 🚌 C++ Bus Ticket System

A simple and efficient command-line based bus ticket automation system written in C++.  
Users can view available bus schedules and purchase tickets.

---

## 🔧 Features

- View bus schedules
- Select a route and time
- Book tickets
- Simple and clear CLI interface

---

## 📦 Installation

> Requires a C++ compiler (e.g., `g++`)

Clone the repository:

```bash
git clone https://github.com/suatbayir1/cpp-bus-ticket-system.git
cd cpp-bus-ticket-system
```

Build the project:

```bash
g++ -o bus_ticket_system main.cpp
```

## ▶️ Usage
Run the program:

```bash
./bus_ticket_system
```
